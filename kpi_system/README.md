# ระบบบันทึกคะแนน KPI ประจำปี — ต่อยอดจากระบบของ KIRO

ระบบบันทึกและวิเคราะห์คะแนน KPI รายเดือน (รอบ ก.ค.–ธ.ค. ปี 2569) สำหรับทีม 4 คน สร้างเป็น **Flask template + models + routes** เพื่อเสียบเข้ากับโครง `base.html` / `Login.html` เดิม

## โครงสร้าง KPI

| กลุ่ม | ข้อ | ใช้ร่วมกัน? | น้ำหนักรวม |
| --- | --- | --- | --- |
| **ส่วนกลาง** | 1–5 | ทั้งทีม (เหมือนกัน) | 50% |
| **รายบุคคล** | 6+ | เฉพาะบุคคล (เพิ่มเองได้) | 50% |
|  |  | **รวม** | **100%** |

### หลักการให้คะแนน (กรอกค่าจริง → ระดับ 1–5 → คะแนน)

```
คะแนนหัวข้อ   = (ระดับ / 5) × น้ำหนัก
คะแนนรวมเดือน = Σ คะแนนทุกหัวข้อ         (เต็ม 100)
คะแนนประจำปี  = เฉลี่ยคะแนนรวม 6 เดือน

```

- **ข้อ 3 (ข้อร้องเรียน)** ใช้ทิศทาง `lower` = **ค่าน้อยยิ่งดี** (0 เคส → ระดับ 5) ตามไฟล์ต้นฉบับ
- แต่ละหัวข้อกำหนด `direction` (`higher`/`lower`) และ `thresholds` (เกณฑ์ 5 ค่า) ได้อิสระ

## ไฟล์ในชุดนี้

```
kpi_system/
├── models.py              # User, KpiCategory, KpiRecord + ฟังก์ชันคำนวณ
├── routes_kpi.py          # Blueprint: kpi.record, main.dashboard, main.team_overview
├── seed_data.py           # เตรียม KPI ส่วนกลาง + ทีม 4 คน + KPI รายบุคคล Anucha
├── templates/kpi/
│   ├── record.html        # หน้าบันทึกคะแนนรายเดือน (คำนวณ real-time)
│   ├── dashboard.html     # สรุปวิเคราะห์รายบุคคล + กราฟ
│   └── team.html          # ภาพรวม/จัดอันดับทั้งทีม
└── static/css/kpi.css     # สไตล์เสริม

```

## วิธีติดตั้ง (เชื่อมกับระบบ KIRO เดิม)

1. **วางไฟล์** — คัดลอกไฟล์เข้าโปรเจกต์ Flask เดิม (ให้ `models.py` ใช้ `db` ตัวเดียวกับ KIRO)
2. **ลงทะเบียน Blueprint** ใน app factory:```python from routes_kpi import kpi, main app.register_blueprint(main) app.register_blueprint(kpi)

```
3. **เพิ่ม CSS** — ต่อ `kpi.css` เข้ากับ `style.css` หรือเพิ่ม `<link>` ใน `base.html`
4. **สร้างตาราง + ข้อมูลตั้งต้น**:```bash
python seed_data.py

``` (รหัสผ่านเริ่มต้นทุกคน = `1234` — **เปลี่ยนก่อนใช้จริง**)
5. **เข้าใช้งาน** — เข้าสู่ระบบ → เมนู "บันทึก KPI รายเดือน" เลือกเดือน → กรอกค่าจริง → ระบบคำนวณให้

## หมายเหตุ

- `models.py` สมมติว่ามีไฟล์ `extensions.py` (`db = SQLAlchemy()`) และ app factory `create_app()` แบบมาตรฐาน หากโครงของ KIRO ต่างจากนี้ ปรับ import ให้ตรง
- endpoint ที่ `base.html` เรียก (`admin.users`, `admin.kpi_categories`, `auth.logout` ฯลฯ) เป็นของ KIRO อยู่แล้ว — ชุดนี้เพิ่มเฉพาะส่วน `kpi.*` และ `main.*`
