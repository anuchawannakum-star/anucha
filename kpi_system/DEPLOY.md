# 🚀 คู่มือ Deploy ระบบ KPI ขึ้นเว็บจริง (ฟรี) — Render.com

ระบบนี้พร้อม deploy ขึ้น **Render.com** แบบฟรี (มีฐานข้อมูล PostgreSQL ฟรีให้ด้วย)
เมื่อ deploy เสร็จ คุณจะได้ URL จริง เช่น `https://kpi-system.onrender.com` ที่ทีมเข้าใช้ได้จากทุกที่

---

## เตรียมตัว (ครั้งเดียว)
1. สมัครบัญชี **GitHub** ฟรี → https://github.com
2. สมัครบัญชี **Render** ฟรี (ล็อกอินด้วย GitHub ได้เลย) → https://render.com

---

## ขั้นตอนที่ 1 — อัปโหลดโค้ดขึ้น GitHub

**วิธี A: ผ่านเว็บ GitHub (ง่ายสุด ไม่ต้องใช้คำสั่ง)**
1. ไปที่ https://github.com/new สร้าง repository ใหม่ ชื่อเช่น `kpi-system` → กด **Create repository**
2. ในหน้า repo กด **"uploading an existing file"**
3. ลากไฟล์**ทั้งหมดในโฟลเดอร์ `kpi_system/`** (รวมโฟลเดอร์ `templates/` และ `static/`) เข้าไป
4. กด **Commit changes**

**วิธี B: ผ่าน Git (ถ้ามีติดตั้ง)**
```bash
cd kpi_system
git init
git add .
git commit -m "KPI system initial"
git branch -M main
git remote add origin https://github.com/<ชื่อคุณ>/kpi-system.git
git push -u origin main
```

---

## ขั้นตอนที่ 2 — Deploy บน Render (อัตโนมัติด้วย Blueprint)

1. ไปที่ Render Dashboard → กด **New +** → เลือก **Blueprint**
2. เชื่อม GitHub แล้วเลือก repo `kpi-system`
3. Render จะอ่านไฟล์ `render.yaml` โดยอัตโนมัติ → เห็น:
   - **kpi-system** (web service)
   - **kpi-db** (PostgreSQL ฟรี)
4. กด **Apply** — Render จะติดตั้ง, สร้างฐานข้อมูล, และรันระบบให้อัตโนมัติ
5. รอ ~2–4 นาที จนสถานะขึ้น **Live** 🎉

> `render.yaml` ตั้งค่าให้แล้ว: สร้าง `SECRET_KEY` อัตโนมัติ, เชื่อม `DATABASE_URL` เข้าฐานข้อมูล และรันด้วย `gunicorn app:app`

---

## ขั้นตอนที่ 3 — เข้าใช้งาน

ระบบจะ **สร้างตาราง + ใส่ข้อมูลตั้งต้นให้อัตโนมัติ** เมื่อเปิดครั้งแรก

## ⚙️ ข้อควรรู้เกี่ยวกับแพลนฟรีของ Render
- **หลับเมื่อไม่ใช้งาน:** เว็บฟรีจะ "หลับ" หลังไม่มีคนเข้า ~15 นาที ครั้งถัดไปที่เปิดจะช้า ~30 วิ (ตื่นขึ้นมา) จากนั้นเร็วปกติ
- **ฐานข้อมูลฟรี:** มีอายุ 90 วัน (ต่ออายุได้) เหมาะกับการใช้งานภายในทีมเล็ก
- ถ้าต้องการให้เว็บไม่หลับ / ฐานข้อมูลถาวร → อัปเกรดเป็นแพลนเสียเงิน (เริ่ม ~$7/เดือน)

---

## 🔁 ทางเลือกอื่น (ถ้าไม่ใช้ Render)
- **Railway.app** — คล้าย Render, มีเครดิตฟรีรายเดือน, ใช้ `Procfile` ที่เตรียมไว้ได้เลย
- **PythonAnywhere** — ฟรี เหมาะกับ Flask + SQLite (ไม่ต้องใช้ Postgres) แต่ตั้งค่ามือมากกว่า

ทุกแพลตฟอร์มใช้ไฟล์ชุดเดียวกันนี้ได้ — เพราะระบบอ่านค่า `DATABASE_URL`, `SECRET_KEY`, `PORT` จาก environment อยู่แล้ว

## ❓ แก้ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|-------|---------|
| Deploy fail ตอน build | เช็ก log — มักเป็น `requirements.txt` ไม่ครบ (ไฟล์นี้เตรียมไว้ครบแล้ว) |
| เปิดเว็บแล้ว error 500 | เช็กว่า `DATABASE_URL` เชื่อมกับฐานข้อมูลแล้ว (Blueprint ทำให้อัตโนมัติ) |
| หน้าตาไม่มี CSS | ตรวจว่าอัปโหลดโฟลเดอร์ `static/` ขึ้น GitHub ครบ |
| ล็อกอินไม่ได้ | ใช้รหัส `1234` — ถ้าฐานข้อมูลใหม่ ระบบจะ seed ให้เองตอนเปิดครั้งแรก |
